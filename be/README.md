in the frontend for /planner, we want to make a urban planner. so what we need right now is:
- create location based search -> grab a localised 3D map (sim city style) - say montreal.
- create a 3D map editor -> allow users to edit the map (create, edit, delete buildings, roads, rivers, parks, etc.)
- create a 3D map viewer -> allow users to view the map (zoom in/out, pan, rotate, etc.)

- use ArcGIS Maps SDK for JavaScript (https://developers.arcgis.com/javascript/latest/visualization/3d-visualization/cities-in-3d/) for maps data and Three.js for 3D rendering and optmized batch rendering.
